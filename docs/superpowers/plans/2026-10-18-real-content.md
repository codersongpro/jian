# 실제 작품 자료 통합

사용자는 기존 설계 구현 중 작품 묶음을 제공하고 포함하라고 요청했다. 기존 관리자·전시 흐름에 실제 데이터를 연결하는 작업이며 공개 게시 요청으로 간주하지 않는다.

원본 메타데이터의 작품 9묶음과 영상 링크 6개의 순서·제목·확인 상태·날짜 근거를 보존한다. `publish_ready:false`를 유지한다. 자료에서 서술한 외부 검색을 이번 작업에서 직접 수행한 것으로 주장하지 않는다. 공개 ZIP 58개 파일의 SHA256을 확인했다. 비공개 ZIP은 전송 한도로 접근하지 못했다.

- [x] 작품 번들 로더와 보안 경계를 테스트 후 구현한다. 미확인 날짜는 null, 문서 날짜의 근거를 따로 표시한다.
- [x] 실제 이미지·다중 페이지·전사 본문·출처 메모를 검토용 단일 랜딩에 연결한다. 영상 6개는 확인 전 외부 링크로만 표시한다.
- [x] 개발 환경의 명시적 검토 모드에서만 후보 자료를 제공한다. 배포 모드에서는 검토 플래그가 있어도 후보 파일 경로를 404로 처리한다. `public`에 후보 파일을 복사하지 않는다.
- [x] 인증된 관리자만 후보를 Supabase에 비공개로 가져올 수 있게 한다. 중복 가져오기는 기존 편집본을 덮어쓰지 않는다. 가져오기는 공개 승인과 별개다.
- [x] 생산용 빈 상태와 개발용 실제 자료의 브라우저 테스트, 빌드·타입검사·전체 단위 테스트를 실행한다.
- [x] 운영 문서·검증 기록·환경 시작 지침을 실제 자료 검토 흐름에 맞춰 갱신한다.

검증: 현재 단위 테스트 15개와 브라우저 18개가 통과했습니다. 프로덕션 빌드·타입 검사도 통과했습니다. 비공개 ZIP은 32MiB 전송 한도로 접근하지 못했으며, 사용자는 아직 Supabase 프로젝트가 없어 실서비스 가져오기/권한 검증은 수행되지 않았습니다. 검수 메모는 관리자 전용 테이블에 분리했습니다.
