- `npm test`: 18개 통과, 실패·스킵 0개. 공개 작품의 본문·이미지 경로·분야·미확인 연도·19쪽 갤러리·링크 순서와 내부 메타데이터 제외를 포함합니다.
- `npm run build`, `npm run typecheck` 통과. 실제 프로덕션 환경에서 데이터베이스 없이 작품을 읽습니다.
- 프로덕션 서버 하나를 대상으로 한 Chromium 데스크톱/모바일 브라우저 테스트 18개 통과. 기존 setup 응답으로 실패하는 것을 재현한 뒤 repository 응답과 실제 파일을 연결했습니다.
- 로컬 `content-bundle/`을 잠시 제외한 상태에서도 빌드 성공. 이때 단위 테스트는 14개 통과, 원래 후보 묶음 전용 검사 4개는 명시적으로 스킵했습니다. 공개 콘텐츠 검사는 모두 실행되었습니다. 검사 후 원래 후보 폴더를 복원했습니다.
- 배포 추적 파일에 `/`와 `/api/catalog` 각각의 공개 Markdown 9개가 포함됩니다. 검토 묶음은 파일 추적에서 제외하여 로컬 빌드 패키지에도 내부 기록을 넣지 않습니다.
- 공개 이미지 40개와 Markdown 9개는 제공된 공개용 파생본과 바이트 단위로 일치합니다. 원래 검수 문서와 비공개 원본 ZIP은 등록하지 않았습니다. 공개 데이터의 날짜·근거·전사/편집 안내를 보존했습니다.
- 코드 리뷰에서 파일 경로·공개/비공개 분리·GitHub 편집 링크를 확인했습니다. 중요한 미해결 지적은 없습니다.
- `/admin`은 GitHub 파일 편집 안내로 전환했습니다. 실제 수정 권한은 GitHub 저장소 권한에 따릅니다. 사이트에서 직접 저장하는 기능은 제공하지 않습니다.
- Vercel 프로젝트 생성·실제 배포, 실제 iOS Safari/Android 실기기는 검증하지 않았습니다. Git 연동을 설정한 Vercel 프로젝트의 재배포가 필요합니다.
- 클라우드 시작 지침 초안을 파일 기반 전시에 맞게 갱신했습니다. 초안 저장은 환경 게시와 다르며, 현재 전시에 Supabase 키는 필요하지 않습니다.

- `npm run build` 및 `npm run typecheck` 통과. 동적 공개 페이지·관리자·보호된 API를 생성했습니다.

## 코드 리뷰와 수정

초기 리뷰에서 변경 행이 없는 작업도 성공으로 표시할 수 있는 문제와 비동기 팝업 차단을 발견했습니다. 변경 행을 확인하고, 미리보기는 명시적인 링크로 열도록 수정했습니다.

실제 자료 연동 리뷰에서는 작품 공개 시 검수 메타데이터도 노출될 수 있는 구조를 발견했습니다. 내부 메모를 관리자 전용 `work_reviews` 테이블로 분리하고, 공개 출처 JSON에는 허용된 필드만 저장하는 SQL 제약과 코드 변환을 추가했습니다. 공개 필드 변환은 실패를 재현한 회귀 테스트가 통과합니다. 데이터베이스 자체의 RLS는 연결 후 실제 검증이 필요합니다.

개발 브라우저 검증 중에는 Next.js 개발 리소스의 127.0.0.1 접근과 초기 hydration 전에 발생한 클릭을 진단했습니다. 공식 설치 문서에 따라 정확한 개발 호스트를 허용하고, JS가 준비되기 전 동적 버튼을 비활성화했습니다. 검토 배너에 의해 감상 설정 패널이 헤더를 덮는 문제도 수정했습니다.

## 외부 연결 및 남은 항목

사용자는 Supabase 프로젝트가 아직 없다고 답했습니다. 현재 실제 연결 정보가 없으므로 아래 항목은 구현했지만 실서비스 통합 검증을 완료하지 않았습니다.

- Supabase SQL 실제 설치, 익명/일반 사용자/관리자 RLS 차이와 관리자 전용 검수 테이블 접근.
- 실제 로그인, 비공개 가져오기/중복 처리/업로드/공개 승인/취소/Range 전송.
- 실제 테마 교체, 대용량 파일 재생, YouTube 재생 시 배경 음악 중단.
- 실제 iOS Safari 및 저사양 실기기 성능.
- GitHub 원격 푸시, Vercel 배포, 클라우드 환경 게시와 새 작업 복원.

YouTube 공식 iframe_api는 프록시 CONNECT 403으로 차단되었습니다. 필요한 도메인을 환경 초안에 추가했지만 아직 런타임에 적용하거나 게시한 것으로 주장하지 않습니다. 이번에 제공된 영상은 메타데이터의 미검수 상태를 유지하여 자동 임베드하지 않습니다.

`jian-private-review.zip`은 파일당 32MiB 전송 한도로 다운로드할 수 없었습니다. 그 안의 원본을 읽거나 검수하거나 반영했다고 주장하지 않습니다. 32MiB 이하 파일/분할 ZIP이 필요합니다.

## 보관과 재사용

공개용 후보 ZIP은 Git에서 제외한 `content-bundle/`에 원래 구조대로 보관했습니다. 공개 폴더에는 복사하지 않았습니다. 소스만 받은 환경에 이 폴더가 없으면 자료 의존 단위 테스트 4개를 명시적으로 스킵합니다. 자료 검토 브라우저 테스트에는 해당 ZIP이 필요합니다. 현재 환경에서는 모든 파일이 있어 스킵 없이 실행했습니다.

기본 npm 캐시는 샌드박스에서 쓸 수 없어 `/workspace/.cache/npm`을 사용했습니다. 저장한 설치 스크립트에도 이 경로를 반영했습니다. 다른 환경에서는 경로 조정이 필요할 수 있습니다. 기존 격리 체크아웃을 유지했고 별도 worktree를 만들지 않았습니다.

설치 스크립트와 시작 지침, 공개 변수 요구사항, YouTube 관련 네트워크 도메인은 환경 초안에 저장했습니다. 사용자가 환경 설정에서 검토·저장한 다음 환경을 게시해야 활성화됩니다. 이 초안 저장은 Vercel 배포와 별개입니다.

마지막 모바일 페이지 이미지 검사는 실제 파일의 decode 완료와 250px 이상 표시 너비를 확인합니다. 좁게 표시되던 갤러리 레이아웃은 실패 재현 후 수정했고 전체 브라우저 검증을 통과했습니다. 실제 화면 캡처에서 브라우저 런타임 오류가 없었습니다.
