# 큰 사진 자동 줄이기 설치 안내

수신함에 5MB가 넘는 사진(최신 휴대폰 원본 사진)이 올라오면 Claude가 받을 수 없습니다. 아래 스크립트를 한 번 설치하면 **매일 새벽 5시대에 큰 사진을 자동으로 줄인 사본으로 바꿔** 두므로, 그 뒤로는 "반영해줘"만 하면 됩니다. 큰 사진을 올린 당일 바로 반영하고 싶으면 휴대폰에 저장해 둔 **「지금 줄이기」 주소**를 한 번 엽니다.

## 하는 일

| 단계 | 내용 |
| --- | --- |
| 1 | 수신함과 하위 폴더에서 4.5MB가 넘는 사진을 찾음 (「반영 완료」「원본 보관」 제외) |
| 2 | 드라이브가 만든 미리보기로 긴 변 2048px JPEG 사본을 같은 폴더·같은 이름으로 만듦 |
| 3 | 사진의 촬영 시각·좌표·업로드 시각을 사본의 '설명'에 적음 (사이트에는 시·군 이름만 공개) |
| 4 | 원본은 수신함 안 「원본 보관」 폴더로 옮김 (삭제하지 않음) |

## 설치 (약 5분, 수신함 주인 계정으로)

1. <https://script.google.com> → **새 프로젝트** → 이름: `지안 수신함 사진 줄이기`
2. 왼쪽 ⚙️ **프로젝트 설정** → 「편집기에서 appsscript.json 매니페스트 파일 표시」 체크
3. 편집기에서 `appsscript.json`을 열고 저장소의 `scripts/drive-inbox-resizer/appsscript.json` 내용으로 바꿈
4. `Code.gs`를 열고 저장소의 `scripts/drive-inbox-resizer/Code.gs` 내용 전체를 붙여 넣고 저장
5. 위쪽 함수 목록에서 **`install`** 선택 → **실행**
6. 권한 요청 창에서 계정 선택 → 「고급」 → 「(프로젝트 이름)(으)로 이동」 → **허용**
   - 드라이브 접근: 수신함 사진을 읽고 사본을 만드는 데 필요
   - 외부 요청: 드라이브 미리보기 이미지를 받는 데 필요
   - 트리거 관리: 하루 한 번 자동 실행 등록에 필요
7. 아래 **실행 기록**에 `줄인 사진 N장` 또는 `줄일 사진 없음`이 나오면 자동 실행 설치 끝
8. **「지금 줄이기」 주소 만들기**: 오른쪽 위 **배포** → **새 배포** → ⚙️ 유형 선택에서 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만**
   - **배포** → 나오는 **웹 앱 URL**(…/exec)을 복사해 휴대폰 즐겨찾기나 홈 화면에 저장
9. 그 주소를 열면 바로 실행되고 `줄인 사진 N장`이 화면에 나옵니다

## 확인과 문제 해결

- **동작 확인**: 왼쪽 ⏰ **트리거**에 `resizeLargePhotos`(일 단위 타이머, 오전 5시~6시)가 보이면 정상입니다.
- **바로 줄이고 싶을 때**: 함수 목록에서 `resizeLargePhotos`를 골라 실행합니다.
- **바로 줄이고 싶을 때**: 저장해 둔 「지금 줄이기」 주소를 엽니다. 편집기에서 `resizeLargePhotos`를 골라 실행해도 같습니다.
- **방금 올린 사진이 그대로일 때**: 드라이브가 미리보기를 만드는 데 몇 분 걸립니다. 몇 분 뒤 다시 열면 됩니다.
- **'다른 실행이 진행 중'이 나올 때**: 새벽 자동 실행과 겹친 것입니다. 1~2분 뒤 다시 엽니다.
- **코드를 고친 뒤**: 배포 → 배포 관리 → ✏️ → 버전 「새 버전」 → 배포 해야 주소에 반영됩니다. 주소는 바뀌지 않습니다.
- **멈추고 싶을 때**: ⏰ 트리거에서 `resizeLargePhotos`를 삭제합니다.
- **원본 정리**: 「원본 보관」의 원본은 작품 반영이 끝난 뒤 직접 지워도 됩니다.

## 보안

- 스크립트는 설치한 계정의 권한으로만 실행되며, 코드에 적힌 수신함 폴더 하나만 다룹니다.
- 「지금 줄이기」 주소는 **나만** 접근으로 배포하므로, 주소가 알려져도 다른 사람은 실행할 수 없습니다. 가족도 누르게 하려면 접근을 「Google 계정이 있는 모든 사용자」로 바꿀 수 있지만, 그러면 주소를 아는 누구나 실행할 수 있습니다(하는 일은 수신함 사진 줄이기뿐).
- 좌표는 비공개 드라이브의 파일 설명에만 남습니다. 사이트에 올릴 때는 `scripts/inbox_photo.py`가 시·군 이름으로 바꾸고 좌표는 버립니다.
- 수신함 폴더를 다른 사람과 공유하고 있다면, 공유받은 사람도 파일 설명(좌표 포함)을 볼 수 있습니다.
